Core libraries live under `apps/packages/core/`. Depend on them with a `path:` dependency from the shell or a feature package (paths match the monorepo layout).

## Module pages

Each topic page below includes **usage examples** and notes on **mixins**: the `core_*` libraries do not ship public `mixin` declarations in their `lib/` APIs; you add app-side mixins on `ConsumerState`, repositories, or notifiers that call `ref.read(...)`.
